# Hasta Arama

Ekip içi hasta arama uygulaması (KUH/AH ameliyat, ameliyat planlama, poliklinik listeleri ve konsey klasörü).

- Bu depoda **hasta verisi yoktur**. Veriler, giriş yapan kullanıcının kendi Google hesabıyla doğrudan Google Sheets/Drive'dan okunur ve cihaza kaydedilmez.
- Yalnızca tablolara erişimi olan ve Google Cloud projesinde test kullanıcısı olarak tanımlı hesaplar kullanabilir.
- Ayarlar: `core.js` (tablo/sütun eşlemeleri, aynı isimli hastalar), `app.js` (`CLIENT_ID`).
